# Audit Checklist

최종본 제출 전 점검 항목. 하드 실패가 있으면 수정 후 재검증한다.

## 하드 실패 (반드시 수정)

- [ ] 원문에 없는 수치, 기술, 성과, 경험이 추가됨
- [ ] 회사명, 직무명, 학교명이 틀림
- [ ] 팀 성과를 개인 성과처럼 표현
- [ ] 문항이 묻는 핵심에 답하지 않음
- [ ] 글자수 초과 (hard maximum 위반)
- [ ] 잠긴 어필 포인트가 설명 없이 삭제됨
- [ ] 블라인드 채용 금지 정보가 포함됨
- [ ] AI 규정상 금지된 작업을 수행함

## 소프트 경고 (보고)

- [ ] 글자수가 제한의 70% 미만
- [ ] 추상어가 행동 증거 없이 남아 있음
- [ ] JD 연결이 약한 문단이 있음
- [ ] 면접에서 꼬리질문이 예상되는 강한 주장
- [ ] 클리셰가 일부 남아 있음

## 의도 보존 점검

- [ ] 잠긴 어필 포인트가 최종본에 살아 있는가
- [ ] 사용자가 강조한 경험의 핵심 내용이 변질되지 않았는가
- [ ] 축약/생략한 내용이 있으면 사유를 적었는가

## 글자수 보고

최종본의 글자수를 다음 기준으로 보고한다:
- 공백 포함 글자수
- 공백 제외 글자수
- 제한 기준이 byte면 UTF-8/EUC-KR byte도 함께

가능하면 `scripts/count_korean_length.py`로 측정한다.
