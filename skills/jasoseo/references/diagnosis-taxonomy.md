# Diagnosis Taxonomy

초안의 약점을 분류한다. 진단 시 이 체계로 문제를 식별하고 우선순위를 매긴다.

## 구조 문제

| ID | 문제 | 시그니처 |
|---|---|---|
| S-1 | 문항 미응답 | 문항이 묻는 핵심 요소가 빠져 있음 |
| S-2 | 두괄식 부재 | 첫 문단이 배경 설명으로 시작하고 주장이 중간 이후에 등장 |
| S-3 | 결론 부재 | 마지막 문단에 직무 연결이나 기여 방향 없이 감상으로 끝남 |
| S-4 | 문단 불균형 | 배경이 50% 이상이고 행동/결과가 부족 |

## 근거 문제

| ID | 문제 | 시그니처 |
|---|---|---|
| E-1 | 추상 역량 나열 | "소통능력", "리더십" 등 역량명만 있고 행동 증거 없음 |
| E-2 | 결과 누락 | 행동은 있는데 "그래서 어떻게 됐는지"가 없음 |
| E-3 | 기여 불분명 | 팀 성과인데 본인이 뭘 했는지 구분 안 됨 |
| E-4 | JD 연결 부족 | 경험은 구체적이나 해당 직무와의 관련성이 안 보임 |

## 문체/표현 문제

| ID | 문제 | 시그니처 |
|---|---|---|
| T-1 | 자소서 클리셰 | "귀사에 기여", "함께 성장", "최선을 다함" |
| T-2 | 회사 칭찬 지원동기 | 회사 소개를 바꿔쓴 듯한 추상적 칭찬이 지원동기의 주요 내용 |
| T-3 | 감정 과잉 | 감정 표현이 많고 구체적 계기/행동이 적음 |
| T-4 | 반복 종결 | 매 문단이 "~를 배웠습니다", "~를 느꼈습니다"로 끝남 |
| T-5 | 기계적 구조 | STAR/CAR 라벨이 보이거나 모든 문단이 동일 패턴 |
| T-6 | 공허한 포부 | "전문가가 되겠습니다" 같은 거창한 비전만, 첫 업무 행동 없음 |

## 제출 리스크

| ID | 문제 | 시그니처 |
|---|---|---|
| R-1 | 면접 방어 불가 | 원문에 없는 수치/성과가 포함되어 질문 시 답변 불가능 |
| R-2 | JD 과적합 | JD 용어가 많은데 실제 경험과 연결 안 됨 |
| R-3 | 글자수 초과/부족 | 제한 기준 대비 초과 또는 70% 미만 |
| R-4 | 의도 손실 | 사용자의 핵심 어필 포인트가 수정 과정에서 사라질 위험 |

## 진단 출력

우선순위 순으로 3~5개 항목을 보고한다:
- ID와 문제명
- 초안에서 해당 부분 인용
- 개선 방향 (구체적으로)
