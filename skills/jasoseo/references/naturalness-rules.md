# Naturalness Rules

자소서 특유의 공식 문체와 AI 생성 흔적을 자연스러운 표현으로 바꾼다. 사실은 보존한다.

## 제거 대상

| ID | 유형 | 예시 |
|---|---|---|
| AN-1 | 대리 작성 문장 | "역량을 강화", "이해도를 높임", "의미 있는 시간" |
| AN-2 | 클리셰 결말 | "귀사에 기여", "함께 성장", "최선을 다함" |
| AN-3 | 노출된 작성 공식 | STAR 라벨, 구호형 소제목, 같은 패턴 반복 |
| AN-4 | 근거 없는 역량명 | "소통능력", "분석력"만 있고 행동 증거 없음 |
| AN-5 | 회사 칭찬 지원동기 | 회사 소개 문구를 바꿔 쓴 추상적 칭찬 |
| AN-6 | 공허한 입사 후 포부 | 장기 비전만 있고 첫 업무 행동 없음 |
| AN-7 | 반복 회고 종결 | "배움", "느낌", "생각"으로만 문단 종결 |
| AN-8 | 감정 과잉 지원동기 | 감정은 큰데 관심 계기와 이후 행동 없음 |
| AN-9 | 과잉 겸손/확신 | 근거 없이 낮추거나 세게 말하는 표현 |
| AN-10 | 면접 방어 불가 | 원문에 없는 수치/기술/성과, 모호한 "주도" |
| AN-11 | JD 키워드 과적합 | 직무 용어만 많고 실제 경험이 묻힘 |

## 자연화 원칙

- 클리셰를 지울 때 그 자리에 담긴 **사실적 의미**가 있으면 살려서 다시 쓴다
- 역량명을 지우면 근거가 되는 행동을 앞으로 끌어온다
- 감정 표현을 줄일 때 계기와 행동은 남긴다
- 모든 문단 끝을 바꿀 필요 없다. 반복이 문제이지 형태 자체가 문제가 아니다
- AI가 쓴 듯한 깔끔한 병렬 구조는, 내용이 진짜면 구조만 약간 흔든다
