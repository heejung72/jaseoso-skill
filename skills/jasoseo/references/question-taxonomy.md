# Question Taxonomy

자소서 문항을 유형별로 분류하고, 각 유형의 필수 답변 요소를 정의한다.

## 문항 유형

| 유형 | 대표 문항 | 필수 요소 |
|---|---|---|
| 지원동기 | "왜 이 회사/직무에 지원했는가" | JD 직무 관심 계기, 관련 경험, 기여 방향 |
| 직무역량 | "직무 관련 역량을 기술하라" | 구체적 경험, 본인 역할, 행동, 결과, JD 연결 |
| 협업/갈등 | "팀에서 갈등을 해결한 경험" | 상황, 조율 방식, 의사결정, 결과 |
| 실패/극복 | "실패 경험과 극복 과정" | 원인 분석, 개선 행동, 재시도 결과 |
| 성격 장단점 | "본인의 장단점" | 장점=직무 연결, 단점=개선 행동 포함 |
| 성장과정 | "성장과정을 기술하라" | 직무 역량 형성에 영향 준 사건 중심 |
| 입사 후 포부 | "입사 후 계획" | JD 기반 첫 기여 행동, 구체적 단기 목표 |
| 자유문항 | "자유롭게 기술" | 가장 강한 직무 관련 경험 하나로 포지셔닝 |

## 판정 규칙

- 문항에 여러 유형이 섞여 있으면 **가장 무거운 유형** 기준으로 답변 구조를 잡는다
- "지원동기와 입사 후 포부" → 지원동기 + 포부 양쪽 요소를 포함
- 문항이 불명확하면 초안의 내용으로 유형을 추정하되, 추정임을 밝힌다

## 공통 원칙

- 문항이 묻는 것에 먼저 답한다. 배경 설명은 최소화.
- 두괄식: 핵심 주장 → 근거(경험/행동/결과) → JD 연결
- 마지막 문장은 "배웠습니다"가 아니라 직무에 어떻게 쓸지로 끝낸다
