# JD Parser Rules

채용공고에서 직무 신호를 추출한다. 가중치 순서: **주요업무 > 자격요건 > 기술/도메인 > 우대사항 > 인재상**.

## 추출 항목

| 항목 | 마커 |
|---|---|
| 회사명 | 회사 소개, About, 기업명 |
| 직무명 | 모집부문, 포지션, 직무 |
| 주요업무 | 담당업무, 수행업무, Responsibilities, What you'll do |
| 자격요건 | 필수요건, 지원자격, Requirements, Must-have |
| 우대사항 | 이런 분이면 좋아요, Preferred, Nice-to-have |
| 기술스택 | 사용 툴, Tech Stack, 필요 역량 |
| 인재상 | 핵심가치, Culture, 이런 사람을 찾습니다 |
| 제출조건 | 제출서류, 지원방법, 전형절차 |

## 사용 원칙

- JD는 자소서에 붙여넣을 **키워드 목록이 아니다**. 읽는 사람이 보고 싶어하는 맥락이다.
- 주요업무의 동사(설계, 운영, 분석, 개발)가 핵심. 초안 경험과 연결되는 것만 반영.
- 우대사항은 초안에 해당 경험이 있을 때만 활용. 없는 경험을 만들지 않는다.
- 인재상은 직접 인용하지 않는다. 초안의 행동이 자연스럽게 보여주도록.
- JD에 나온 기술이 초안에 없으면 넣지 않는다.
